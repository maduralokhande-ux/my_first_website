# Madura Lokhande – Portfolio

Next.js 14 · TypeScript · Tailwind CSS · Lucide icons

## Run locally
```bash
npm install
npm run dev      # http://localhost:3000
```

## Edit content
Everything lives in `lib/content.ts`. Search for `TODO` to fill placeholders
(college name, LinkedIn link). Put images in `/public`.
Colours are in `tailwind.config.ts`.

## Deploy on Vercel
1. Push this folder to a GitHub repo (`git init && git add . && git commit -m "init"`).
2. Go to vercel.com → **Add New → Project** → import the repo.
3. Keep the defaults (Next.js is auto-detected) and click **Deploy**.
Every future `git push` redeploys automatically.
